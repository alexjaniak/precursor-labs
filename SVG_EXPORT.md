# SVG Export Notes

The SVG path is generated by `src/logo-svg-export.js` with marching squares over the same scalar field used by the fragment shader:

- each dot is a circle SDF: `length(p - dot.xy) - dot.radius * dotScale`
- `all dots` and custom blend groups use the shader's polynomial smooth-min
- `separate dots` and `none` group dots use hard `min`
- custom groups are smooth-unioned internally, then hard-unioned against other groups

The editor's `SVG` button exports the current on-screen dot state with a solid background. `SVG Clear` exports the same path without a background rectangle, so the SVG is transparent around the mark.

`npm run export:svg` writes `exports/liquid-dot-logo-default.svg`. `npm run export:svg:transparent` writes `exports/liquid-dot-logo-default-transparent.svg`. Both scripts use the current final square pixel mark defaults:

- `unionMode`: `custom groups`
- `liquidBlend`: `0.060`
- `dotScale`: `0.733`
- `squareStep`: `0.115`
- `squareExtent`: `3`
- `showGrid`: `false`
- `dotColor`: `#f5f2ed`
- `backgroundColor`: `#151414`

## Quality

Marching squares samples the field directly, so it preserves the shader's liquid bridges and group behavior without inventing a separate vector construction model. The default script uses a `1024x1024` field sample and a very small polyline simplification tolerance. Increase `resolution` for tighter curvature and decrease `simplifyTolerance` when the output will be enlarged aggressively.

The main tradeoff is that the output is a filled polyline contour, not analytic Bezier geometry. It is faithful to the raster field but can contain many points. A direct circle-and-bridge Bezier builder would produce cleaner hand-editable paths, but it would need a separate model for smooth-min blends and would diverge from the shader sooner. Raster tracing from a canvas capture is simpler to bolt on, but it bakes in antialiasing and loses the exact SDF threshold.

## Merge Back

This prototype is isolated to:

- `src/logo-svg-export.js`
- the `SVG` and `SVG Clear` action hooks in `src/main.js`
- `scripts/export-default-svg.mjs`
- `package.json` export scripts
- `SVG_EXPORT.md`
- optional generated files in `exports/`

To merge into the main editor, cherry-pick or copy those files/sections into the main branch, run `npm install` if dependencies are not present, then verify with `npm run build`, `npm run export:svg`, and `npm run export:svg:transparent`. Keep `exports/` only if you want sample artifacts checked in; otherwise treat it as generated output.
